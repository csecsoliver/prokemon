# Prokemon

A játék az 1. generációs pokemon másolata.

## Jellemzők
- 🎮 Lineáris játékmenet javított navigációval
- 💾 Fájlba mentés és betöltés
- ⚔️ Továbbfejlesztett harci rendszer (támadás, védekezés, item használata, menekülés)
- 📖 Interaktív Prokedex böngészővel
- 🌟 Starter Pokemon választás
- 🎨 Javított vizuális megjelenés

## Használat
1. **Új játék**: Válassz starter Pokemot és kezdd el a kalandot
2. **Prokedex**: Böngészd a Pokemonokat típus és statisztikák szerint
3. **Mentés/Betöltés**: Mentsd el a haladásod és folytasd később
